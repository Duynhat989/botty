# DynaGeo (frontend)

Giao diện **DynaGeo** — chuyển bài toán thành hình vẽ canvas tương tác; tham số có thể chỉnh trực tiếp trên hình.

## Chạy local

```bash
npm install
npm run dev
```

Dev: `http://localhost:5173` (hoặc cổng Vite in ra terminal).

## Biến môi trường

- `VITE_API_URL` — URL API backend (mặc định `http://localhost:2053/api`)
- `VITE_SITE_URL` — URL site production cho meta/SEO (mặc định `https://dynageo.app`)
